# 標準設定への復元

設定画面の「機能」「MetallKraftインターフェース」「FluidNC」タブ下部にある「標準に戻す」から開きます。
工場出荷状態ではなく、その基板で保存した標準設定へ戻す機能です。

## 使い方

1. 機械と主軸を停止し、正常に動く設定を確認します。
2. 初回は「標準設定・バックアップ」を開き、「現在の設定を標準として保存」を押します。
3. 以降は比較画面で標準と異なる項目が黄色になります。項目ごとの復元、または「すべて標準に戻す」を選べます。
4. 機械設定を復元した場合は「再起動して適用」を明示的に押します。自動では再起動しません。

復元前にバックアップを保存します。通信失敗や停止状態を確認できない場合は中断し、自動再試行しません。途中で失敗した場合は一部だけ保存されている可能性があるため、内容を確認してください。

## 対象と対象外

- 対象: 実行時の機械設定YAML、保存された画面設定、許可した表示・動作設定。
- 対象外: Wi-Fiなどの接続設定、通知の接続情報、座標のゼロ点、SDカードのファイル、ファームウェア、UI本体。
- 比較時はFluidNC標準コマンドで実行時YAMLを一時ファイルに出力します。常時監視の追加ではなく、操作時だけ状態確認用の接続を開きます。
- 基板識別情報またはFluidNCの版が保存時と異なる場合は復元しません。別の機械に標準設定ファイルを流用しないでください。

標準は本体Flashの `mk-defaults.json`、復元直前のバックアップは `mk-before-restore.json`、比較用の一時ファイルは `mk-runtime.yaml` です。これらは機械固有の情報を含むため、公開リリースには同梱しません。

比較画面の黄色表示は、元の設定画面の入力欄の色とは別です。画面設定だけを戻した場合は画面の再読み込みで適用します。
