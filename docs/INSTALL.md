# 自分のFluidNCにUIを導入する

[トップへ戻る](../README.md)

この手順は、**正常動作しているFluidNCの画面だけを置き換える**ものです。MetallKraftの機械やMKS製ボードである必要はありません。自分のYAML・配線・校正値・Wi-Fi設定はそのまま使います。

## 1. 導入前の確認

- 基準環境はFluidNC v4.0.3 Wi-Fi版 / WebUI-3 v3.0.10です。他の版・基板は動作確認が必要です。
- このUIはXYZのCNC向けです。加工ファイル選択・プレビュー・開始には、FluidNCでSDカードを認識できることが必要です。
- 主軸・原点復帰・プローブなどは、各自の機械で設定済みの機能を使います。画面を入れるだけでは有効になりません。
- 基板のFlashに空き容量があることを確認してください。公開ファイルのサイズは[`install/manifest.json`](../install/manifest.json)にあります。

**すでにFluidNCが動いている場合、UI導入のための再インストールやYAML変更は不要です。** `fresh-install`やFlash初期化は行いません。

まだFluidNCがない場合は、[公式インストール手順](https://github.com/bdring/fluidnc-wiki-content/blob/main/installation.md)で、自分の基板に合うファームウェアとYAMLを用意し、起動エラーを解消してから戻ってください。ESP32とESP32-S3は区別します。同梱のMAX用設定例を利用する人だけ、[任意の基板設定](BOARD.md)へ進んでください。

## 2. ダウンロードとバックアップ

1. [ZIPをダウンロード](https://github.com/MetallMeister/metallkraft-fluidnc/archive/refs/heads/main.zip)して展開します。ビルドやプログラミングは不要です。
2. 機械を停止し、再接続や画面読み込みでモータ・主軸が不用意に動かない状態にします。配線の抜き差しは電源を切って行い、ファイル転送中の基板電源は切りません。
3. [FluidNC Web Installer](https://installer.fluidnc.com/fluidnc)をChromeまたはEdgeで開き、USBで接続します。他のシリアル接続アプリは閉じてください。
4. `File browser` → **Flash**から、現在のYAML、`preferences.json`、`index.html.gz`と他の画面ファイルをダウンロードして保管します。Wi-Fi設定は別管理なので自分で控えます。

初回導入では`preferences.json`の上書きにより、**表示設定と登録マクロが置き換わります。** 残したいマクロや設定は、バックアップを参照して導入後に再登録してください。すでにこのUIを使っている場合は[更新手順](UPDATE.md)で既存設定を維持できます。

## 3. UIファイルだけを入れる

`File browser`の**Flash直下（`/`）**へ、`install/ui/`内の次の7ファイルをアップロードします。**`install/boards/`のYAMLはアップロードしません。Active configも変更しません。**

| ファイル名 | 内容 |
| --- | --- |
| `index.html.gz` | カスタムWebUI本体 |
| `theme-metallkraft.gz` | 色・文字・配置 |
| `lang-ja.json.gz` | 日本語表記 |
| `preferences.json` | 初期表示・移動量・移動速度など |
| `metallkraft-preview.html.gz` | 加工予定経路・位置・通過推定 |
| `metallkraft-links.html` | サイト・ショップ・コミュニティ |
| `metallkraft-news.html` | お知らせ |

**`.gz`は解凍せず、そのまま送ります。** macOS等が自動解凍した場合は、展開前の`.gz`を使用してください。ZIPやフォルダ自体ではなく、表のファイルを送ります。

同名の非圧縮ファイル（`index.html`など）が以前からある場合は、先にバックアップしてからその競合ファイルだけを削除します。Flash全体を初期化する必要はありません。

## 4. 画面を開く

1. 自分の基板のIPアドレスをブラウザで開き、キャッシュを無視して再読み込みします。他の人のIPアドレスは使用しません。
2. MetallKraftロゴ・日本語表示・加工予定経路・加工ファイル欄を確認します。UIだけの変更なら、YAMLの再読み込みのための基板再起動は不要です。
3. SDの認識、座標と状態表示、必要な表示設定・マクロを確認します。表示を確認するために加工を開始しないでください。

基板のIPへ`http://`で接続します。インターネットへ基板を直接公開したり、ルーターでポート転送したりしないでください。MetallMeisterのお知らせ・外部リンクは機械の通信とは別です。

## 5. 加工前に

- 各自の機械で、方向・移動量・可動範囲・原点復帰・主軸・プローブ・非常停止を確認する。同梱の[基板設定例](BOARD.md)は他基板の確認手順や完成済み設定を代替しません。
- ジョグ初期値は10 mm / 500 mm/min。**初回確認は移動量と速度を小さくして**、可動範囲と方向を1軸ずつ確認する。
- GコードはSDカードへ入れる。SDでファイルを選ぶと予定経路へ反映されるが、選択だけでは実行しない。
- **大きい「加工開始」を押すと確認ダイアログなしで開始する。** 工具・材料・固定・作業原点を事前に確認する。
- 位置・軌跡・進捗は基板報告に基づく表示です。実切削や衝突の有無は判定できません。クイック停止は物理的な非常停止の代わりにはなりません。

## よくある問題

| 症状 | 確認すること |
| --- | --- |
| SD / Flashがわからない | UIはFlash、加工GコードはSD |
| 起動時に設定エラー | 各自のActive config、基板に合うピン設定、YAML字下げ、Startup messages。UI導入でYAMLを置き換えない |
| 標準画面のまま | `index.html.gz`、競合する`index.html`、ブラウザキャッシュ |
| 配置や日本語が反映されない | `preferences.json`・テーマ・言語ファイルがFlash直下にあるか |
| No SD card | カード、フォーマット、接点、各自の基板のSPI/CS設定。画面が出ることとSD認識は別 |
| 主軸・プローブ・原点復帰が動かない | 各自のYAML・配線・機能設定。UIはピンを自動設定しません |
| お知らせだけ読み込めない | 外部インターネット接続。機械制御とは別で、受信内容は文字だけを表示 |

戻す場合は[更新・元に戻す](UPDATE.md)へ。他のボードでの動作報告も[GitHub Issues](https://github.com/MetallMeister/metallkraft-fluidnc/issues)で歓迎します。
