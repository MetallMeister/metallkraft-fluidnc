# 開発・変更範囲

## 通常の導入ではビルド不要

`install/`が生成済みの配布物です。基板へ送るものは[導入手順](INSTALL.md)に限定してください。

## 再ビルド

Node.js 22以上とnpmを使用します。リポジトリ直下で実行します。

```sh
npm ci
npm run build
npm test
```

`dist-standard/`を生成し、導入に必要な7ファイルだけを`install/ui/`へコピーします。`install/manifest.json`にはサイズとSHA-256が記録されます。YAMLはビルドで自動生成・上書きしません。

`vendor/index.html.gz`はハッシュで固定した公式WebUI-3 v3.0.10です。既知の差分を`standard/display-patches.mjs`等で適用します。元の断片が一致しなければ停止するため、別バージョンのminified HTMLをそのまま差し替えないでください。

元のWebUIのソースから確認する場合は、`vendor/esp3d-webui-v3.0.10-source.tar.gz`を別ディレクトリで展開します。上流の`README.md`、`config/webpack.prod.js`、`package-lock.json`が含まれ、上流UIはそのルートで依存関係を導入して`npm run build`で生成します。上流再ビルドはツールチェーンによってminify結果が変わり得るため、その出力がパッチ対象と同じハッシュになることは保証していません。MetallKraftの再生成は同梱の固定アーティファクトから行います。

## 変更しているもの

- 色、文字、配置、折りたたみ、操作ラベル。
- ジョグ移動量・速度の選択UI、状態に応じた操作可否、主軸表示。
- SDファイル選択とプレビュー、開始ボタンへの集約。送信先のコマンド生成・送信は標準WebUIを利用。
- 位置報告を読む工具位置・通過推定、読込進捗からの参考時間表示。
- 文字だけを表示するMetallMeisterのお知らせ。
- 停止後の復帰案内。既存の機械状態と利用者のクリックを表示に利用し、コマンド送信や追加ポーリングは行いません。
- 利用者が明示的に保存した基板内標準値との比較・個別復元・一括復元。復元時は標準UIの状態表示とFluidNCの既存ファイル・ESPコマンドを使用します。

**CSSだけではなくブラウザ側JavaScriptも変更しています。** 通信処理を新規実装した独立コントローラではありませんが、標準画面と完全に同じ実行コードでもありません。選択時・開始直前のSDファイル読込、単位やモードの初期照会、利用者が開いたときだけ行う設定比較・復元処理を追加しています。ブラウザ上の復元機能は別のWebSocketを開かず、制御用定期ポーリングも追加していません。

FluidNCのステップ生成・機械設定・ファームウェアには手を加えていません。異なる基板でUIを使う場合も、その機械で検証済みのYAMLが別途必要です。

## 表示と運用の制限

- 予定経路はGコード全機能のシミュレータではなく、衝突・保持力・工具長の安全を判定しません。プレビュー不能や未対応コードを見落としたまま実行しないでください。
- 灰色は観測した位置に基づく推定です。通信欠落・重複経路・座標系変更等では色を付けない場合があります。SD読込率を通過済み領域へ変換しません。
- 進捗・残り時間は読込状態からの目安で、実加工の完了率とは一致しないことがあります。
- ソフト停止は通信と基板の応答に依存します。物理非常停止を代替しません。
- 標準クイック停止はSafety Door指令です。この画面の復帰案内は、リセットで加工を中止し、原点確認後にファイルを選び直す手順を示します。途中再開の案内ではありません。
- スリープ後はリセットし、アラーム内容に応じて解除・原点確認が必要です。復帰案内は安全確認や原点の実測を代替しません。状態の根拠: [FluidNC v4.0.3 Protocol.cpp](https://github.com/bdring/FluidNC/blob/v4.0.3/FluidNC/src/Protocol.cpp)、[アラーム定義](https://github.com/bdring/FluidNC/blob/v4.0.3/FluidNC/src/Alarm.h)。
- 外部通信はお知らせページの取得（`metallmeister.net`）と、利用者が開く外部リンクです。お知らせ取得時にGコード・座標を送る処理はありません。接続先サーバーには通常のHTTPアクセスとして送信元IP等が見えます。
- 公開版のマクロは空。自動実行マクロ、Wi-Fi資格情報、個人のGコードは含めません。
- 公開版には、利用者の`mk-defaults.json`、`mk-before-restore.json`、比較用`mk-runtime.yaml`を含めません。

## 検証

`npm test`は位置追跡、通過推定、進捗、経路処理、設定復元の安全条件、配布ファイルの整合性を確認します。ブラウザテストは実機ではなくローカルの模擬コントローラにのみ接続します。

```sh
npm exec playwright install chromium
npm run test:ui
```

ブラウザテストにはPlaywrightが必要です。これは機械の実動作・校正・安全回路の検証を代替しません。`docs/screen.png`も模擬データによる表示例です。

公開時には個人の基板から取得した設定をそのままコピーせず、差分・秘密情報・マクロ内容を確認してください。
