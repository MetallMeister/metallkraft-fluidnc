# MKS DLC32 MAX用の基板設定

[導入手順へ](INSTALL.md)

対象: Makerbase **MKS DLC32 MAX V1.0_002 / ESP32-S3**。通常版DLC32とはピン配置が異なります。

同梱ファイル: [`install/boards/mks-dlc32-max-v1.0/config.yaml`](../install/boards/mks-dlc32-max-v1.0/config.yaml)

## 設定の状態

このYAMLは基板の初期起動・UI導入用です。元の基板で起動を確認していますが、モータ・主軸未接続時の設定で、機械の移動精度や方向は未検証です。汎用の完成済み加工設定ではありません。

| 項目 | 初期設定 |
| --- | --- |
| 駆動 | XYZ、StepStickのSTEP/DIR制御 |
| steps/mm | XYZとも800（1.8度、1/16、ねじリード4 mmを仮定） |
| 最高送り | X/Y 3000、Z 1000 mm/min |
| 加速度 | X/Y 100、Z 60 mm/s² |
| 仮の可動範囲 | X 300 / Y 200 / Z 70 mm |
| 原点復帰・リミット | 無効 |
| ソフトリミット | 無効。上記寸法を設定しても範囲外移動を防止しない |
| プローブ・主軸・冷却 | 未設定 / 無効 |
| 外付け安全入力 | 未設定。物理的な非常停止を構成するものではない |
| ドライバ電流・マイクロステップ | YAMLでは設定しない。ドライバ側で確認する |

`steps/mm = 1回転のフルステップ数 × マイクロステップ数 ÷ ねじリード(mm)`。減速・増速がある場合はその比率も必要です。NEMAの外形規格だけでは設定値は決まりません。

## ピン一覧

| 信号 | GPIO |
| --- | --- |
| 共通ENABLE | 8 |
| X STEP / DIR | 16 / 15 |
| Y STEP / DIR | 7 / 6（現設定はDIR反転） |
| Z STEP / DIR | 5 / 4 |
| SD MISO / MOSI / SCK / CS | 12 / 14 / 13 / 21 |

出典: [Makerbase公式 MKS DLC32 MAX V1.0_002 PIN.pdf](https://github.com/makerbase-mks/MKS-DLC32/blob/main/MKS--DLC32-MAX-main/firmware/MKS%20DLC32%20MAX%20V1.0_002%20PIN.pdf)。手元の基板リビジョンと必ず照合してください。

## 加工に進むための確認

1. 基板・ドライバ型番、電源、モータ配線、電流設定、マイクロステップを確認する。
2. 小さい移動量・低い速度で1軸ずつ方向と実移動量を確認し、校正する。Y反転の要否も機械によって異なる。
3. 実可動範囲、原点スイッチの取付位置・論理・電圧、原点復帰方向を確定して設定する。
4. 原点復帰と必要なリミットを検証する。解除されている制限を「保護済み」と扱わない。
5. 主軸ドライバの型番、制御信号、停止条件、回転数対応を確定する。BLDCを基板のブラシ付きモータ用出力へ直結しない。
6. プローブの極性・電圧・厚さ・最大移動距離を確認して有効化する。初期の画面パラメータを実物の値とみなさない。
7. 物理非常停止、配線断線時や通信断時の挙動を確認する。

現在のYAMLにはソフトスタートや主軸始動待ち時間の設定も含まれません。GUIの表示を変えるだけで主軸の立ち上がり制御が追加されるわけではありません。
